
# Organized — iOS Checklist App

A personal productivity app for managing daily tasks,
custom checklists, categories, and recurring routines.

## Planned Features

- [ ] Daily checklists
- [ ] Create custom lists
- [ ] Categories and folders
- [ ] Task completion and progress tracking
- [ ] Reminders and notifications
- [ ] Recurring tasks
- [ ] iPhone Home Screen widgets
- [ ] iCloud synchronization

## Technology

- Swift
- SwiftUI
- SwiftData
- UserNotifications
- WidgetKit
- CloudKit

## Development Roadmap

1. Build the core checklist interface.
2. Add task creation and local persistence.
3. Implement reminders and recurring tasks.
4. Add Home Screen widgets.
5. Configure iCloud synchronization.
6. Test and prepare for release.

## Project Status

Planning and initial development.
